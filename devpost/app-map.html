ContextGuard · Developer guide

App Map

A compact guide to the local scan, optional Gemini boundary, and the code that displays the results.

What the app does

ContextGuard checks pasted prompt text against a defined set of local patterns, replaces supported matches with placeholders, and shows counts plus a cleaned copy-ready prompt. Gemini is optional and off by default. If the user explicitly scans with it enabled, the app sends only the locally redacted text and validates the structured response before display.

Reference route through the code

Reference only · not an interactive code tour

  1. app.py — Find the Scan & Mask Prompt button block. It rejects blank input, runs scan_prompt() first, and calls Gemini only when the toggle is enabled and the user submits.
  2. scanner.py — scan_prompt() returns redacted text and counts. analyze_with_gemini() accepts that redacted text plus the API key; RiskAssessment enforces the score, level, and exactly two findings.
  3. app.py and tests/test_scanner.py — The UI shows the local result and any validated assessment. Offline tests check that the Gemini request contains redacted text, and cover missing keys, API/timeout errors, and invalid responses.

To change this, start here

  • Supported detectors, labels, and replacement patterns: DETECTOR_LABELS and _RULES.
  • Gemini model, instructions, and response shape: _GEMINI_MODEL, _GEMINI_SYSTEM_INSTRUCTION, and RiskAssessment.
  • Labels, toggles, status, warnings, and result presentation: app.py.
  • Expected redactions, response validation, and mocked API behavior: tests/test_scanner.py.

A practice to reuse

Turn an important boundary into something observable. ContextGuard keeps redaction in scan_prompt(), limits the Gemini function to redacted text, and tests the outgoing request with a mock. A separate startup check caught Streamlit's network-wide default; .streamlit/config.toml now binds to 127.0.0.1, and the correction is recorded in devpost/spec.md. On another project, pair a requirement with both a focused test and a check of the running behavior that could violate it.

Run it again

From the project folder in PowerShell:

.\myvenv\Scripts\python.exe -m streamlit run app.py

Open http://localhost:8501. The app binds to localhost. Gemini is optional; without a key, local scans still work and an enabled scan shows a missing-key message.

Run offline tests with .\myvenv\Scripts\python.exe -m unittest discover -s tests.
